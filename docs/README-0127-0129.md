# OHBONO Wallet — Batch 0127–0129

This batch adds **regression protection, order-state safety and deployment
validation**.

## 0127

Re-runs the most important wallet invariants as framework-independent tests.

## 0128

Adds configurable order-state guards.

This avoids assuming that a particular OpenCart status ID means "paid" or
"refundable" on every installation.

## 0129

Adds a deployment validator so missing critical extension files are detected
before installation.

## What this batch does NOT do

It does not claim that the live staging environment is healthy.

It does not:

- fake staging results
- enable production events
- modify Journal
- modify OpenCart core
- change wallet balances

## Current state

The codebase is now ready for the **actual staging execution/evidence phase**.

The next batch should focus on recording real results from:

- wallet-only checkout
- partial wallet checkout
- external payment failure
- duplicate callback
- refund/reversal
- browser refresh
- cross-customer protection
- ledger reconciliation

Only real staging evidence should move the release gate toward production.
