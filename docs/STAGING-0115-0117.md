# Confirmed Staging Wiring — 0115–0117

## Phase 1 — Verify

Before enabling event registration:

```text
OpenCart VERSION
        +
event table
        +
Journal checkout route
        +
Journal checkout callback
        +
wallet tables
```

must all be confirmed on staging.

## Phase 2 — Register

The registry adds only the explicitly defined OHBONO events.

If the target installation uses a different event trigger/action syntax, stop
and adapt the definitions before enabling them.

## Phase 3 — Journal UI

Connect the wallet presentation and checkout bridge to the actual Journal
checkout template/callback.

Do not edit Journal core files.

## Phase 4 — Wallet-only test

Example:

```text
Order total:      ₹500
Wallet balance:   ₹800
Wallet selected:  ₹500
External payment: Not required

Expected:
Wallet debit:     ₹500
Remaining:        ₹0
Order:            Paid
```

## Phase 5 — Partial-wallet test

Example:

```text
Order total:      ₹1,000
Wallet balance:   ₹600
Wallet selected:  ₹400
External payment: ₹600 SUCCESS

Expected:

External payment: ₹600
Remaining:        ₹0

```

## Phase 6 — Failure test

```text
Order total:      ₹1,000
Wallet selected:  ₹400
External payment: ₹600 FAILED

Expected:
Wallet:           ₹400 debit initially
Payment state:    Reconciliation required
After approved
reversal:
Wallet:           ₹400 credit reversal
Net wallet impact: ₹0
```

## Phase 7 — Retry/idempotency

Repeat the same wallet callback with the same order.

Expected:

```text
One wallet debit
One payment reference
Same transaction returned
No second deduction
```

## Phase 8 — Browser refresh

Refresh after the wallet callback.

Expected:

```text
No duplicate debit
No duplicate reversal
Order/payment state remains consistent
```
