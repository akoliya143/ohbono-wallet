# OHBONO Wallet — Batch 0088–0090

This batch begins checkout integration without touching wallet balances.

## Flow

```text
Checkout
   |
   v
Wallet available?
   |
   v
Calculate maximum usable amount
   |
   v
Customer chooses wallet amount
   |
   v
Show remaining order total
   |
   v
Order/payment layer
   |
   +----> Final server-side validation
   |
   +----> Future atomic wallet deduction
```

## Deliberate boundary

0088–0090 only calculate and display wallet usage.

There is no `UPDATE wallet SET balance = ...` in the checkout calculation
layer.

This prevents a customer from reducing wallet funds merely by calling a
preview endpoint.

## Next

0091–0093 should implement the server-side wallet payment method and final
authorization flow, including order-total revalidation, wallet row locking,
idempotent transaction references and safe failure handling.
