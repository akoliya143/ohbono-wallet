# OHBONO Wallet — Batch 0103–0105

This batch is a security and diagnostics milestone.

## Security improvements

### 1. Amount normalization

All wallet amounts are normalized to four decimal places before financial
logic.

### 2. Strict references

References accept only:

```text
A-Z a-z 0-9 . _ : -
```

### 3. Trusted payment references

Wallet capture now derives the payment reference from the trusted order ID:

```text
OBW-PAY-{order_id}
```

This is safer than accepting an arbitrary browser-generated reference.

### 4. Mutation methods use POST

Refund and wallet capture endpoints reject non-POST requests.

Normal OpenCart authentication and admin permission checks remain required.

### 5. Schema diagnostics

The diagnostic validator checks the core wallet tables before production use.
