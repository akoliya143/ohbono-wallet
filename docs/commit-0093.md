## Critical integration note

The checkout/order implementation must calculate the final trusted order total
on the server immediately before calling `OhbonoWalletPaymentService`.

Do not use the browser's `order_total` as authoritative payment data.

The payment reference must be generated by the trusted order/payment layer and
must remain stable across retries. Reusing that reference makes retries
idempotent and prevents duplicate wallet deductions.
