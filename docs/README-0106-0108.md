# OHBONO Wallet — Batch 0106–0108

This batch makes the extension safer to install and prepares the actual
OpenCart checkout test stage.

## Installation

The installer is designed to be repeatable for the tables introduced by the
wallet workflow.

The uninstaller deliberately preserves financial data.

## Permissions

Recommended:

```text
Reconciliation  = Access
Refund          = Access + Modify
Diagnostics     = Access
```

Refund modification should be restricted to trusted administrators.

## Checkout test matrix

| Scenario | Expected |
|---|---|
| Wallet covers 100% | Paid by wallet |
| Wallet covers part + external succeeds | Paid |
| Wallet captured + external fails | Reconciliation required |
| No wallet amount | Awaiting payment |
| Wallet > order total | Rejected |

## Journal

The target environment uses OpenCart 4.1.x with Journal Theme 3.2. The wallet
integration should be attached through supported extension/event mechanisms and
checkout hooks, not by modifying OpenCart or Journal core files.
