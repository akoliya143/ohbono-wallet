# OHBONO Wallet — Batch 0121–0123

This is the **staging-results and release-blocker layer**.

## 0121 — Ledger verification

The invariant checker verifies:

```text
Transaction N opening balance
        =
Transaction N-1 closing balance
```

and:

```text
debit:  before - amount = after
credit: before + amount = after
```

Finally:

```text
wallet.current_balance
        =
ledger final balance
```

No automatic repair is performed.

## 0122 — Staging result tracking

The admin can record:

```text
PASS
FAIL
BLOCKED
NOT RUN
```

This keeps test evidence separate from the wallet ledger.

## 0123 — Release blocker

A release is blocked if any required scenario is not `pass`.

Required scenarios include:

- Wallet-only payment
- Partial wallet + external success
- External failure + reconciliation
- Insufficient balance
- Wallet > order total
- Duplicate callback
- Browser refresh
- Refund
- Reversal
- Cross-customer protection

## Important

This batch does **not** claim that your staging environment has passed these
tests. It creates the mechanisms and checklist needed to record real results.

The next batch should be based on the actual failures observed on your
OpenCart 4.1.x + Journal Theme 3.2 staging installation.
