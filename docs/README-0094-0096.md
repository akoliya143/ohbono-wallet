# OHBONO Wallet — Batch 0094–0096

This batch connects wallet payment to actual OpenCart orders.

## Architecture

```text
OpenCart Checkout
       |
       v
Create / validate order
       |
       v
Trusted order total
       |
       v
Wallet contribution
       |
       +-------------------+
       |                   |
       v                   v
Wallet capture       Remaining payment
       |                   |
       v                   v
Wallet transaction   External payment
       |                   |
       +---------+---------+
                 |
                 v
          Final payment state
```

## Important limitation

The wallet transaction and a secondary payment transaction are different
systems. A production implementation must not assume that both succeed or fail
together automatically.

If wallet money is captured and the external payment fails, the order/payment
workflow needs an explicit compensation action, such as a wallet reversal,
before the payment is considered failed.

## What is ready

- Order ownership check
- Final order total revalidation
- Wallet capture
- Partial-payment arithmetic
- Order-to-wallet transaction lookup
