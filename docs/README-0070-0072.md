# OHBONO Wallet — Batch 0070–0072

This batch completes the practical queue-processing layer introduced in
0067–0069.

## Flow

```text
Wallet transaction
       ↓
Email queue
       ↓
Cron worker
       ↓
Claim pending item
       ↓
Send email
   ↙       ↘
Sent      Retry
             ↓
          5 attempts
             ↓
           Failed
             ↓
       Admin can retry
```

## Cron

```bash
*/5 * * * * php /path/to/opencart/upload/cron/wallet_email_worker.php 20 >> /var/log/ohbono-wallet-email.log 2>&1
```

Do not copy the example path blindly. Replace it with the real installation
path on the production server.

## Important

The email queue is informational infrastructure. It must never be allowed
to roll back or block a completed wallet balance mutation.
