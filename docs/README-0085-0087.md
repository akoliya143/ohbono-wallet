# OHBONO Wallet — Batch 0085–0087

This batch improves the customer-facing wallet experience before checkout
integration.

## Customer flow

```text
OHBONO Wallet
      |
      +----> Current Balance
      |
      +----> Transaction History
                 |
                 +----> Pagination
                 |
                 +----> Transaction Detail
      |
      +----> Email Preferences
```

## Security

The customer-facing transaction detail query requires the authenticated
customer ID. A customer cannot access another customer's transaction by
changing the transaction ID in the URL.

## Currency

Display formatting is delegated to OpenCart's currency service. Stored wallet
amounts remain numeric values and should not contain currency symbols.
