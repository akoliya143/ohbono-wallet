# OHBONO Wallet — Batch 0079–0081

This batch enables controlled administrator wallet adjustments.

## Flow

```text
Admin
  |
  v
Permission check
  |
  v
Customer + wallet validation
  |
  v
Amount + reason + unique reference
  |
  v
START TRANSACTION
  |
  +--> Lock wallet
  |
  +--> Check duplicate reference
  |
  +--> Validate balance for debit
  |
  +--> Update wallet balance
  |
  +--> Insert wallet transaction
  |
  +--> Insert admin audit
  |
  v
COMMIT
```

The audit record and financial transaction are committed together.

## Important

The manual adjustment service should be the only path used by the admin UI.
Do not directly update `wallet.balance` from a controller.
