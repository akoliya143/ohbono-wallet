# OHBONO Wallet — Installation Guide 0106–0108

## 1. Backup first

Before installing or upgrading:

- Database backup
- OpenCart files backup
- Existing wallet transaction backup

Do not test migration scripts on production first.

## 2. Upload

Copy the contents of `upload/` into the OpenCart installation.

Do not replace OpenCart core files.

## 3. Install

Run the extension installer from the project's supported extension workflow.

The installer creates missing workflow/audit tables without deleting existing
financial data.

## 4. Permissions

Grant only the admin users/groups that need:

- Wallet reconciliation access
- Wallet refund modification
- Wallet diagnostics access

## 5. Verify schema

Open the wallet diagnostics route while logged into admin.

Expected:

```json
{
  "valid": true,
  "missing_tables": []
}
```

## 6. Journal Theme

The wallet extension should integrate through OpenCart extension/event
mechanisms and Journal's supported checkout customization points.

Do not edit Journal core files.

## 7. Production rule

Never run an uninstall operation that drops wallet financial tables.

Wallet history is accounting data and should be retained.
