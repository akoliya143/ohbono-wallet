# Journal Theme 3.2 Integration Notes

The project uses OpenCart 4.1.x + Journal Theme 3.2.

This batch deliberately avoids making assumptions about the current Journal
checkout markup.

## Recommended approach

Use:

```text
Journal checkout UI
       |
       v
OHBONO wallet UI
       |
       v
OHBONO JSON calculation
       |
       v
OpenCart trusted checkout
       |
       v
OHBONO wallet payment service
```

The JavaScript UI may display wallet balance and remaining order total, but the
server must recalculate all financial values.

## Do not

- Edit Journal core files.
- Edit OpenCart core checkout controllers.
- Trust a hidden wallet balance field.
- Deduct money from a browser AJAX preview.
- Treat order creation as payment success.
- Generate financial references solely in JavaScript.

## Before UI hookup

Inspect the live Journal checkout page and identify:

- Total element
- Payment method container
- Confirm-order callback
- AJAX checkout endpoint
- Error rendering area

Only then add a small Journal-compatible presentation layer.
