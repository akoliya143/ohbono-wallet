```text
OpenCart 4.1.x
      |
      +---- Event boundary
      |
      +---- Checkout

      |

                  |
                  v
          OHBONO Wallet Service
                  |
                  v
             Wallet Ledger
```

## Key safety rule

Events do not automatically mean payment success.

The wallet is mutated only by the trusted wallet payment service.
